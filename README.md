Aquadecor

```bash
npm install
npm run dev
```

Краткая инструкция:

1. Все изображения хранятся в соответствующих папках для конкретных страниц - там сейчас заглушки.
2. Для разделов Проектирование, Реставрация, Купели и Ёмкости из пролипропилена необходимо в папке app
   создать соответствующие подпапки и прокинуть линки, примера в файле Offers.tsx:

```
<Link href="/servicies/overflowPools">
    <InfoBlockMainPge
    textHeader="Переливные бассейны"
    cost={"от 237 000"}
    imgSrc={buildPool.src}
    />
</Link>
```

В случае появления большого количества текстов рекомендован создавать в каждой папке app файл
texts.ts, где в формате json хранить весь текст, примеров данных файлов нет, так как не было
получено примеров текста - вся информация написанная на текущий момент является мокнутой, найденной в интернете
и подлежит замене

В качестве стилей использовался tailwind - вот ссылка на документацию: https://v2.tailwindcss.com/docs/flex-wrap

Для заливки не ленлинг генерить статику для получения out файла, пример можно посмотреть тут:
https://nextjs.org/docs/app/api-reference/config/next-config-js/output
